# DOM-Mutualism
*HTML, CSS and JS working together, with nothing hidden in between.*

> Pre-alpha. Everything can and will change. Not ready for use.

> Uses ES6 modules, so it needs a local server (opening via `file://` won't work).

See [philosophy.md](./philosophy.md) for what this lib is aiming to be.

Currently, I am running an experiment where I build a very small, single-page video game using my library's philosophy of how a page should work,
but without actually using the library.
This will allow me to see friction points and help me figure out what is needed in the library.
